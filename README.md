# Project Progress Dashboard | Excel & VBA

An interactive Excel dashboard designed to monitor project progress, analyze delivery performance, and track monthly trends.

## 📊 Project Overview

This project transforms raw project delivery data into an interactive dashboard that provides a clear overview of project performance through KPIs, visualizations, and dynamic filters.

## 🎯 Dashboard KPIs

- Total Projects: 340
- Total Meters Delivered: 60,322
- Top Project by Deliveries: SHOURA
- Top Delivered Product: Canopy

## 📈 Dashboard Insights

The dashboard includes visual analysis of:

- Most Delivered Products / Files
- Meters Delivered by Project
- Monthly Delivery Trends

## ⚙️ Interactive Features

- Dynamic filtering by Year and Project
- VBA-powered ActiveX ComboBoxes
- Automatic updates for KPIs and charts
- Navigation to raw data through a clickable logo

## 🚀 How to Use

1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Enable macros if prompted and if you trust the file.
4. Use the Year and Project dropdown filters to explore the dashboard.

> Note: VBA functionality requires a desktop version of Microsoft Excel with macros enabled. The dashboard's macro features may not work in Excel Online.
